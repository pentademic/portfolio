## Voir le portfolio

Le site est déployé automatiquement via GitHub Pages depuis la branche `main`.  
Lien direct à mettre sur le CV : **https://pentademic.github.io/portfolio**

> **Prérequis GitHub Pages :** dans les *Settings* du dépôt → *Pages*,
> sélectionner **Source : Deploy from a branch**, branche `main`, dossier `/ (root)`.

## Mettre à jour le contenu

Toutes les sections (Hero, Compétences, Expériences, Projets, Formation, Contact)
se trouvent dans `index.html`. Modifier le HTML directement, puis pousser sur `main` :
les changements sont publiés en quelques secondes.

Pour modifier les couleurs ou le layout, éditer les variables CSS au début de `style.css`.
